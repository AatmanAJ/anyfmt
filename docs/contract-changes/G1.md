# Contract change requests from lane G1 (image + metadata tools)

None of these block the lane: each has a local workaround that is already in
place. They make the shared contracts say what the editors already do.

## 1. Declare the editor-only option keys in `ToolSchemas` (Sources/Shared/Specs.swift)

**What.** Four options the runners read are not in their schemas, so the CLI
(`--opt key=value`), the matrix runner and `ToolSpec.defaultOptions` can't see them.

| Tool | Key | Kind | Default | Read by |
|---|---|---|---|---|
| `image.annotate` | `annotations` | `.text` (JSON array, see `Annotation`) | `"[]"` | `AnnotateImageRunner` |
| `image.addBackground` | `angle` | `.slider(min: 0, max: 360, step: 1, unit: "°")` | `.int(135)` | `AddBackgroundRunner` (CSS convention: 0° up, 90° right) |
| `image.redact` | `color` | `.color` | `"#000000"`, visibleWhen style == solid | `RedactImageRunner` |
| `image.collage` | `order` | `.text` | `""` (1-based indices, like `imagesToPDF`) | `CollageRunner` |

**Proposed code.**

```swift
public static let annotate = OptionsSchema("tool.annotate", [
    OptionSpec("annotations", L("Annotations"), .text, default: .string("[]"),
               help: L("JSON array of marks; coordinates 0…1 from the top-left")),
])
// ToolCatalog: ToolSpec(ToolIDs.annotateImage, …, schema: ToolSchemas.annotate, suffix: "annotated")

// ToolSchemas.addBackground, after "color2":
OptionSpec("angle", L("Gradient angle"), .slider(min: 0, max: 360, step: 1, unit: "°"), default: .int(135),
           visibleWhen: ["fill": .string("gradient")]),
// ToolSchemas.redact, after "style":
OptionSpec("color", L("Fill colour"), .color, default: .string("#000000"), visibleWhen: ["style": .string("solid")]),
// ToolSchemas.collage, at the end:
OptionSpec("order", L("Order"), .text, default: .string(""), help: L("Comma-separated input indices; empty keeps drag order")),
```

**Workaround now.** Runners read each key with the same default, so a missing
key behaves exactly like the proposed default.

## 2. A hook to present a tool's result (Sources/Tools/Editors/EditorFactory.swift)

**What.** Read QR / barcode writes `<name>-codes.txt`, but the user should also
see the codes with Copy buttons and a confirm-before-open "Open link…"
(BUILD.md §7 tool 11). Something has to call the presenter when that job ends.

**Proposed code** (EditorFactory, forwarding like `open`):

```swift
/// Shows extra UI for a finished tool job (e.g. the codes found by Read QR).
/// Returns false when the tool has nothing to show beyond its files.
@discardableResult
public static func presentResult(_ tool: ToolSpec, outputs: [URL]) -> Bool {
    if ImageEditors.presentResult(tool, outputs: outputs) { return true }
    return false
}
```

The Jobs UI (lane C) calls `EditorFactory.presentResult(spec, outputs: urls)`
after a tool job succeeds. `ImageEditors.presentResult` is already implemented
and tested; it opens `CodeResultPresenter` (which also copies the codes, as
BUILD.md promises) and returns false for every other tool.

## 3. `EditorWindow.present` size parameter (Sources/Tools/Editors/Shell/EditorShell.swift)

**What.** Annotate and Collage want 1040 × 700, Images → PDF 1000 × 680,
Metadata 940 × 660. Proposed: `present(title:content:size: NSSize = defaultSize, onClose:)`.

**Workaround now.** `ImageEditors.open` resizes and re-centres the window right
after `present` returns (before it is drawn, so there's no visible jump).

## 4. Shell help text for Before / After

**What.** The toggle's tooltip says "Hold to compare with the original (B)",
but it's a toggle (press B or click to flip; nothing happens on hold). Either
make it momentary (press-and-hold) or change the help to
"Compare with the original (B)". Verified separately that the bare-B shortcut
does **not** swallow a typed "b" in text fields (app-hosted test
`testTypingBInMetadataFieldIsNotSwallowed`).
